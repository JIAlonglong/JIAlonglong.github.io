UniMemVLA integrates memory into both reasoning and action generation for long-horizon robotic manipulation. A perceptual memory compressor condenses visual history into compact tokens, which are interleaved with historical subgoals to form an event-bounded memory sequence. This shared context guides subgoal reasoning and continuous action generation within a single model, helping robots use past interactions to complete memory-intensive tasks.
